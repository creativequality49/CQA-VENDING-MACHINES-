# CQA design system

Use existing components and semantic tokens first. Proposed palette: background #050505, surface #191219, primary #FF2D8D, foreground #FFFFFF, secondary accent #00E5FF (restrained). Use dark text on pink buttons; verify contrast for every actual pairing. Two-tone headings use pink and neutral white. Dark glass surfaces must retain legibility without blur. Use visible focus, keyboard navigation, labelled controls, reduced motion, responsive layouts, and 44px touch targets where practical. Preserve existing checkout and delivery state semantics. Prioritize homepage, marketplace, onboarding, checkout, library and dashboards. Run npm run lint, npm run typecheck, npm run build, npm run test:commerce and npm run test:customer-ui before release; report unavailable checks. No production deployment.
